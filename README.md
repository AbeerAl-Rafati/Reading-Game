# رحلة القراءة

لعبة تساعدك تقرأي لساعات: مراحل قصيرة، استراحات محترمة، وجيب فضول بتسجلي فيه اللي بدك تدوري عليه وبتدوري عليه بالاستراحة.

## النشر على GitHub Pages

1. افتحي github.com وسوّي ريبو جديد (مثلًا `reading-quest`) وخليه Public.
2. اضغطي **Add file** ثم **Upload files**، واسحبي `index.html` (و`README.md` إذا بدك).
3. اضغطي **Commit changes**.
4. من **Settings** ثم **Pages**: تحت Source اختاري **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، واضغطي Save.
5. بعد دقيقة أو اثنتين بيطلع الرابط: `https://اسم-حسابك.github.io/reading-quest/`
